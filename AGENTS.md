# Nexus-Studio — Agent Rules

## Git / GitHub (standing rules)

1. **Never tag/identify the AI in commits or pushes.** All commits and pushes use the user's own GitHub account, with no AI attribution in commit messages, co-author lines, or anywhere else.
2. **Never push to GitHub until the user has tested the changes and explicitly given the ok.** The user works in batches — make changes locally (local commits are fine) and wait for the user's approval before pushing. No "death by 1000 commits" / trickle pushes.
